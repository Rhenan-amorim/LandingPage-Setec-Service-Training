# Landing Page - Setec Service Training

Landing page desenvolvida para a divulgacao de servicos de treinamento, com foco em comunicacao digital, organizacao de informacoes e experiencia do usuario.

## Objetivo

O projeto foi criado para apresentar treinamentos e servicos relacionados, estruturando o conteudo de forma clara, visual e orientada a navegacao do usuario.

## Tecnologias utilizadas

- HTML estático
- CSS
- JavaScript

## Funcionalidades

- Apresentacao de servicos de treinamento
- Organizacao de informacoes em secoes
- Estrutura de navegacao
- Layout focado em comunicacao digital
- Chamadas para acao (CTAs), quando aplicavel

## Processo de desenvolvimento

Este projeto foi desenvolvido com apoio de inteligencia artificial utilizando Claude Code.

Minha participacao incluiu a definicao do objetivo da pagina, briefing, estrutura de conteudo, direcionamento visual, requisitos, revisao do resultado, testes e ajustes finais.

A inteligencia artificial foi utilizada como ferramenta de apoio ao desenvolvimento. O projeto foi revisado, adaptado e organizado para publicacao no GitHub.

## Como executar localmente

1. Clone este repositorio:

```bash
git clone https://github.com/Rhenan-amorim/LandingPage-Setec-Service-Training.git
```

2. Acesse a pasta do projeto:

```bash
cd LandingPage-Setec-Service-Training
```

3. Inicie um servidor estático (Python 3):

```bash
python -m http.server 8765 --bind 127.0.0.1
```

4. Abra `http://127.0.0.1:8765/` no navegador. Não há instalação npm nem etapa de build nesta versão.

## Verificações e direção visual

A direção aprovada é **Marinho imersivo**, com barra inferior de vidro: sete destinos no desktop, quatro no mobile e três no menu superior complementar. O planejamento está em [design-study/checklist-implementacao.md](design-study/checklist-implementacao.md), e os resultados em [design-study/verificacao.md](design-study/verificacao.md).

Verificação de sintaxe JavaScript:

```bash
node --check script.js
```

Verificação estrutural, links locais, conteúdo e integridade de imagens contra o HEAD do Git (referência anterior ao redesign):

```bash
python design-study/check_project.py
```

O formulário prepara uma mensagem para o WhatsApp; a pessoa conclui o envio lá. Não existe backend de propostas neste repositório.
